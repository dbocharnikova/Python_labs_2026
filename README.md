## объяснения
различие: строка (str) и число (int или float) различабтся тем, что строки-последовательность символов, используется для текста, а числа-математическое значение, используется для вычислений. \
\
порядок вычислений: в Python действует стандартный математический приоритет (сначала выполняются умножения [*] и деление [/], а затем сложение[+] и вычитание [-]; скобки [()] меняют порядок, заставляя сначала выполнить действия внутри них) \
\
Временная переменная служит "буфером" для сохранения значения первой переменной перед ее перезаписью. \
Без временной переменной значение первой будет перезаписано значением второй, и исходное значение первой будет безвозвратно потеряно. \
Временная переменная гарантирует, что оба значения поменяются местами корректно, без потери данных. \
\
Форматирование денежного вывода: денежные значения обычно представлены дробными числами (float) в программе, но чтобы соблюдать два знака после запятой в f-строках используется спецификатор формата [:.2f].

## объяснения
Бесконечный цикл while завершиться принудительно благодаря оператору break. Завершение произойдет, когда пользователь введет нужные данные. ИЛИ завершится принудительно, при divisor, которое увеличивается на 1 на каждой интерации, тк рано или поздно условие цикла станет ложным. \
Цикл for .. in range(n): всегда завершится, тк range(n) генерирует конечную последовательнсть чисел. Как только итератор переберет все элементы, цикл автоматически остановится. \
\
Функция range(a,b) по умолчанию работает следующим образом: 
1) Не включает правую границу b;
2) Всегда идет с шагом +1:
* Если a<b, нам нужно range(a,b+1), чтобы включить b;
* Если a>b, то range(a,b) вернет пустую последовательность, тк шаг по умолчанию положительный, и программа не начнет отсчет. Нужно явно указать отрицательный шаг: range(a,b-1,-1).
